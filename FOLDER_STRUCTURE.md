## Key Directories

### `/extension`
Contains the content script that runs on YouTube pages to detect video pauses and extract frames.

### `/src/popup`
React components and styles for the extension popup UI.

### `/src/sidepanel`
React components and styles for the side panel that displays extracted text.

### `/public/libs`
Third-party JavaScript libraries (Tesseract.js) used for OCR functionality.

### `/dist`
Compiled and bundled output files ready for Chrome extension installation (generated by `npm run build`).

### `/src/shared`
Shared utilities and constants used across multiple components.

## Build Process

1. **Development**: `npm run dev` - Runs Vite dev server
2. **Build**: `npm run build` - Compiles React components and outputs to `/dist`
3. **Lint**: `npm run lint` - Runs ESLint on source files

## Extension Files

- **`manifest.json`** - Defines extension permissions, entry points, and configuration
- **`background.js`** - Service worker for message routing
- **`extension/content.js`** - Content script for YouTube page interaction
- **`public/popup.html`** & **`public/sidepanel.html`** - HTML entry points for React apps
